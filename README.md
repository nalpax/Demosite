# Mellow Coffee — учебный сайт кофейни

Учебный пример для курса **Vibentry**. Кофейня, цены, график и контакты вымышленные. Это не реальный бизнес. Заказы не отправляются, оплата не подключена.

## Как запустить

**Вариант 1.** Откройте `index.html` двойным щелчком. Сайт работает без интернета и без сервера.

**Вариант 2: простой локальный сервер.** В папке проекта выполните одну из команд:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000.

Сборка, npm и фреймворки не нужны. Всё написано на обычных HTML, CSS и JavaScript.

### Как поменять меню

Откройте `data.js`. Каждый товар — это объект в массиве `PRODUCTS`:

```js
{ id: 'latte', category: 'coffee', name: 'Латте', price: 24000, // 240 ₽ в копейках
  description: '…', image: 'assets/photos/latte.jpg',
  sizes: 'cup',      // набор объёмов из SIZES или null
  milk: true, extraShot: true, syrup: true }
```

Надбавки за объём, молоко, сироп и дополнительный шот задаются там же, в `SIZES`, `MILKS`, `SYRUPS` и `EXTRA_SHOT`.

### Как подключить сервер

В `orders.js` замените тело функции `submit(order)` на запрос к API, например `fetch('/api/orders', …)`. Функция должна вернуть Promise с сохранённым заказом. Интерфейс менять не нужно.

## Разделы главной страницы

Первый экран с фото и короткими фактами о меню, бегущая строка, подборка «С чего начать», меню, подбор напитка в два вопроса, «О кофейне» с фотоколлажем, «Как готовим вашу чашку», самовывоз по шагам, частые вопросы, контакты и подвал.

Оформление: тёмная тёплая палитра (эспрессо, карамель, латте, приглушённый шалфей). У кнопок при наведении есть подъём, заливка слева направо и блик, у стрелки внутри кнопки — сдвиг. Карточки при наведении поднимаются, фото в них плавно приближается. Ссылки меню подчёркиваются, иконка корзины покачивается. При включённой настройке «уменьшить движение» (`prefers-reduced-motion`) анимации отключаются.

## Демонстрационные функции

- **Меню:** 15 позиций в категориях «Кофе», «Холодные напитки», «Чай и матча» и «Десерты». Есть переключение категорий и поиск по названию (регистр и «ё» не важны). Для пустой выдачи показывается сообщение и кнопка «Сбросить поиск».
- **Окно выбора:** объём, молоко, дополнительный шот и сироп. Набор опций зависит от товара: у десертов нет опций, у эспрессо только 30 и 60 мл. Надбавка показана рядом с каждой опцией. Цена пересчитывается сразу. Окно закрывается кнопкой, клавишей Esc и нажатием на фон. Пока окно открыто, фокус остаётся внутри и прокрутка страницы заблокирована. После закрытия фокус возвращается на кнопку, с которой окно открыли.
- **Корзина:** на компьютере открывается боковой панелью, на телефоне на весь экран. Одинаковые конфигурации объединяются, разные идут отдельными строками. Можно менять количество и удалять позиции. Показаны опции и сумма, есть пустое состояние. Корзина хранится в `localStorage` под ключом `mellow.cart.v1`. Счётчик в шапке анимируется при добавлении, после добавления появляется уведомление.
- **Оформление самовывоза:** имя, телефон (нужно 11 цифр, или 10, если номер начинается с 9), время («Как можно скорее» или «Ко времени» на сегодня или завтра по учебному графику 08:00–20:45) и комментарий. Ошибки показываются рядом с полями. Введённые данные сохраняются при возврате к корзине. Кнопку нельзя нажать повторно, пока заказ сохраняется. Учебный заказ с номером `MC-001`, `MC-002` и так далее сохраняется в `localStorage` (`mellow.orders.v1`).
- Рядом с подтверждением написано: «Демонстрационный заказ. Данные не отправляются в кофейню, оплата не списывается».
- Кнопки в разделе «Контакты» показывают сообщение «Учебный пример: здесь подключается контакт заказчика».

## Что нужно заполнить заказчику

На странице эти места отмечены пометкой `[заполнить]`:

- адрес кофейни;
- телефон;
- почта и мессенджеры;
- реальные часы работы (сейчас стоит учебный график 08:00–21:00);
- реальные цены (сейчас они учебные).
